# قالب نمایشی برگ — آرایشگاه و آکادمی مردانه

این پروژه یک قالب نمایشی فرانت‌اند با React و Vite است. تمام متن‌ها به فارسی دری و چیدمان راست‌به‌چپ (RTL) تنظیم شده‌اند.

## اجرا در کمپیوتر
1. Node.js نسخه LTS را نصب کنید.
2. این پوشه را باز کنید.
3. در ترمینال اجرا کنید:
   ```bash
   npm install
   npm run dev
   ```
4. آدرسی را که Vite نشان می‌دهد در مرورگر باز کنید.

## ساخت نسخه قابل نشر
```bash
npm run build
```
فایل‌های آماده نشر در پوشه `dist` ساخته می‌شوند.

## نشر رایگان و ساخت لینک عمومی
- ساده‌ترین راه: وارد حساب Netlify شوید و پوشه `dist` را در بخش نشر دستی (Deploy manually) بکشید و رها کنید.
- یا پروژه را در GitHub قرار دهید و از Vercel یا Netlify به GitHub وصل کنید. پس از نشر، یک لینک عمومی دریافت می‌کنید که دیگران نیز می‌توانند باز کنند.

## نکته مهم
این فقط قالب UI است؛ هنوز به Django، دیتابیس، ورود کاربران، مدیریت واقعی شاگردان/کارمندان و ذخیره‌سازی ویدیو وصل نشده است. فرم دیدگاه صرفاً نمایشی است و داده‌ها بعد از تازه‌سازی صفحه باقی نمی‌مانند. تصاویر نمونه از Unsplash بارگذاری می‌شوند. نام، آدرس و معلومات تماس نمونه‌اند و باید با معلومات واقعی جایگزین شوند.
